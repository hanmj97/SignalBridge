# SignalBridge V2-3.1 — 사이드바 대분류 메뉴

## 변경 내용

- 청년정책·채용: `정책·채용 통합 검색`, `관심 정책·채용 알림`
- Engineering: `릴리스 대시보드`, `개발 릴리스 목록`, `변경 이력`, `데이터 소스`, `시스템 상태`, `릴리스 관심 알림`
- 내 계정: `마이페이지`
- 세 그룹은 펼침/접힘 가능. 기본으로 사용자 서비스 그룹이 열림.
- 관심 정책·채용 알림 메뉴는 **기존 청년정책 페이지 내부의 V2-3 알림 영역으로 스크롤**함. 새로운 경로/API를 만들지 않음.
- 모바일 메뉴, 상세 패널 Portal, 회원 인증, 백엔드 API, DB, Discord/Resend 연동은 그대로 유지.

## 적용 방법

1. 현재 프로젝트(`D:\Projects\SignalBridge`)의 `frontend/src/App.tsx`, `OpportunitiesPanel.tsx`, `styles.css`를 백업한다.
2. ZIP을 기존 프로젝트 폴더에 덮어쓴다.
3. `docker compose @compose exec web npm run build` 로 TypeScript 빌드한다. (`$compose`는 기존 V2-3 목록을 사용)
4. 브라우저에서 Ctrl+F5로 새로고침한다.

## 확인 항목

1. 왼쪽에 대분류 3개가 표시되고 각 그룹을 펼치거나 닫을 수 있는지 확인.
2. 처음 접속할 때 청년정책·채용만 열려 있는지 확인.
3. 관심 정책·채용 알림 클릭 시 기존 V2-3 알림 영역으로 이동하는지 확인.
4. Engineering 하위 기존 6개 메뉴가 정상 이동하는지 확인.
5. 마이페이지, 로그인 및 모바일 햄버거 메뉴가 정상 동작하는지 확인.
6. 기존 우측 상세 패널이 화면 오른쪽에서 열리는지 확인.

## 적용 주의

V2-3 버전을 기준으로 최소 3개 프런트엔드 파일을 교체한다. 이 패치 이후 해당 파일들을 별도로 수정했다면 변경분을 비교·병합해야 한다.
